# Mes 8 · Elizabeth Hernández Mayoral

Periodo: **10 de noviembre al 10 de diciembre de 2026**.

## Publicación en GitHub Pages

1. Descarga y descomprime el archivo ZIP.
2. Abre el repositorio de Elizabeth en GitHub.
3. Sustituye el contenido anterior por `index.html` y copia también la carpeta `assets` completa.
4. Confirma los cambios con un mensaje como: `Actualizar régimen de Elizabeth al Mes 8`.
5. Espera uno o dos minutos y abre la dirección de GitHub Pages.

El sitio no necesita fuentes ni librerías externas. La carpeta `assets` contiene las dos fotografías usadas en la sección de registro visual y debe conservarse junto a `index.html`.

Los botones de la rutina abren guías visuales o videos de técnica de ACE Fitness y recursos del NHS, por lo que requieren conexión a internet.
